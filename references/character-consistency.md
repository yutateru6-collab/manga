# Character, Scene, and Product Consistency

## Character lock sheet

For each recurring character record:

- role in story
- approximate age presentation
- body silhouette/proportions
- face shape
- eyes/brows
- hair shape/color/part
- outfit by layer
- footwear
- accessories
- recurring prop
- color anchors
- default posture
- expression range
- left/right asymmetries
- forbidden changes

Use concrete observable traits, not vague adjectives.

Bad: “friendly student, cute hairstyle.”

Better: “short straight black bob ending at jawline; blunt bangs above brows; round black-frame glasses; navy cardigan over white shirt; red fabric pencil case carried in left hand.”

## Scene lock sheet

Record:

- room/location geometry
- fixed objects
- window/door position
- desk/device position
- time of day
- light direction
- palette/material anchors
- signage/text that must remain exact

## Product lock sheet

Treat the product as a recurring character.

Record:

- exact logo source
- casing/device dimensions or silhouette
- product colors
- buttons/controls
- UI navigation state
- screenshot source file
- what can change between panels
- what must never be invented

If an accurate screenshot exists, use it as a reference rather than asking an image model to invent the interface.

## Continuity ledger per panel

Track:

| Panel | Character state | Clothing | Held props | Product/UI state | Scene state | Change from prior panel |
|---|---|---|---|---|---|---|

Any change must be intentional or corrected.

## Reference-generation strategy

Before final art, create:

1. character sheet(s)
2. key scene establishing reference(s)
3. product/device reference(s)
4. optional expression sheet for main character

For multi-page stories, prefer reusing the same reference assets instead of regenerating identity from text each time.
