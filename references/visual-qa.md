# Visual QA Checklist

Use `BLOCKER`, `MAJOR`, `MINOR`, or `PASS`.

## A. Advertising

- [ ] First panel has a clear attention reason.
- [ ] Hook is relevant to the intended audience.
- [ ] Panel 2 continues the hook premise.
- [ ] Product enters naturally and is identifiable.
- [ ] Mechanism/value is concrete enough to understand.
- [ ] Proof is real and appropriately represented.
- [ ] CTA is one clear next action.
- [ ] No unsupported superlative/guarantee/urgency.

## B. Story / manga

- [ ] Panel reading order is unambiguous.
- [ ] Shot changes create pace rather than confusion.
- [ ] Gaze and motion support reading flow.
- [ ] Emotional transition is visible.
- [ ] No accidental time/space jump.
- [ ] No redundant panel that repeats the same beat.

## C. Character continuity

- [ ] face/hair stable
- [ ] clothing stable
- [ ] accessories/props stable
- [ ] age/body silhouette stable
- [ ] no duplicate/extra character
- [ ] handed props do not jump sides without reason

## D. Product truth

- [ ] logo/spelling exact if shown
- [ ] product shape/colors faithful
- [ ] UI based on source, not invented as real
- [ ] correct feature demonstrated
- [ ] price/offer current and sourced if shown
- [ ] numbers/reviews/awards sourced

## E. Japanese copy

- [ ] exact wording matches approved copy
- [ ] natural Japanese
- [ ] speaker assignment correct
- [ ] line breaks natural
- [ ] no character corruption
- [ ] no clipped text
- [ ] no text hidden by art
- [ ] CTA exact

## F. Mobile layout

- [ ] main text readable at normal phone viewing size
- [ ] first panel remains legible in feed preview
- [ ] essential content away from crop-risk edges
- [ ] contrast sufficient
- [ ] balloons have padding
- [ ] visual hierarchy clear within ~2 seconds

## G. Image integrity

- [ ] hands/limbs plausible for the selected style
- [ ] no merged objects
- [ ] no extra fingers/duplicate facial parts that distract
- [ ] background geometry not contradictory
- [ ] no accidental watermark/text
- [ ] no unrequested third-party mark

## H. Revision decision

For each defect record:

| Severity | Tag | Location | Problem | Smallest safe fix | Requires regeneration? |
|---|---|---|---|---|---|

Blocking defects include:

- wrong product/claim/price/CTA
- unreadable or incorrect key Japanese text
- misleading fake proof
- broken panel order
- severe character/product mismatch
- crop removing the key action
